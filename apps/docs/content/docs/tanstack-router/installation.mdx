## Installation

To install BProgress, run the following command:

<Tabs groupId="packageManager" items={['npm', 'pnpm', 'yarn', 'bun']} persist>
  <Tab value="npm">```bash npm install @bprogress/tanstack-router ```</Tab>
  <Tab value="pnpm">```bash pnpm add @bprogress/tanstack-router ```</Tab>
  <Tab value="yarn">```bash yarn add @bprogress/tanstack-router ```</Tab>
  <Tab value="bun">```bash bun add @bprogress/tanstack-router ```</Tab>
</Tabs>

Now you are ready to use BProgress in your TanStack Router application!

<Callout type="info" title="Compatibility">
  This package works with both:
  - **TanStack Router** (SPA mode)
  - **TanStack Start** (SSR/SSG mode)
</Callout>
