## Overview

`ProgressProvider` enables automatic progress bars for all navigation events. It must be used **inside** the router (e.g. in your root route component), not wrapping `<RouterProvider>`.

## Import

```tsx
import { ProgressProvider } from '@bprogress/tanstack-router';
```

## Usage

Wrap your root route content (e.g. `<Outlet />` or `{children}`) with `ProgressProvider`. It uses `useRouter()` internally, so it must be a descendant of `RouterProvider`.

### TanStack Router (SPA)

```tsx
// In your root route component
<ProgressProvider>
  <Outlet />
</ProgressProvider>
```

### TanStack Start (SSR)

In `routes/__root.tsx`, wrap the body content. The provider handles SSR via `<ClientOnly>` internally.

```tsx
<ProgressProvider>
  {children}
</ProgressProvider>
```

## Props

All props from [@bprogress/react ProgressProvider](/docs/react/components/progress-provider) are supported, plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `startPosition` | `number` | `0` | Starting position of the progress bar (0-1) |
| `delay` | `number` | `0` | Delay in ms before showing the progress bar |
| `stopDelay` | `number` | `0` | Delay in ms before hiding the progress bar |
| `disableSameURL` | `boolean` | `true` | Disable progress bar when navigating to the same URL |

## Examples

### Basic

```tsx
<ProgressProvider>
  <Outlet />
</ProgressProvider>
```

### Custom Color and Height

```tsx
<ProgressProvider color="#ff0000" height="4px">
  <Outlet />
</ProgressProvider>
```

### With Delay

Useful to prevent flickering on fast navigations:

```tsx
<ProgressProvider delay={100} stopDelay={200}>
  <Outlet />
</ProgressProvider>
```

### Allow Same URL Navigation

```tsx
<ProgressProvider disableSameURL={false}>
  <Outlet />
</ProgressProvider>
```

### Custom Options

```tsx
<ProgressProvider
  options={{
    minimum: 0.1,
    trickle: true,
    trickleSpeed: 200,
    showSpinner: true,
  }}
>
  <Outlet />
</ProgressProvider>
```
