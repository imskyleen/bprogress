## Import

Import the `ProgressProvider` in your root route or main entry file.

```tsx
import { ProgressProvider } from '@bprogress/tanstack-router';
```

## Usage

Wrap your application with the `ProgressProvider` component:

```tsx
<ProgressProvider>
  <RouterProvider router={router} />
</ProgressProvider>
```

## Example: TanStack Router (SPA)

```tsx title="src/main.tsx"
import { StrictMode } from 'react'
import ReactDOM from 'react-dom/client'
import {
  RouterProvider,
  createRootRoute,
  createRouter,
} from '@tanstack/react-router'
import { ProgressProvider } from '@bprogress/tanstack-router'

const rootRoute = createRootRoute({
  component: () => (
    <ProgressProvider>
      <Outlet />
    </ProgressProvider>
  ),
})

// ... define your routes

const router = createRouter({ routeTree })

ReactDOM.createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <RouterProvider router={router} />
  </StrictMode>,
)
```

## Example: TanStack Start (SSR)

```tsx title="app/routes/__root.tsx"
import { createRootRoute, Outlet } from '@tanstack/react-router'
import { ProgressProvider } from '@bprogress/tanstack-router'

export const Route = createRootRoute({
  component: RootComponent,
})

function RootComponent() {
  return (
    <html lang="en">
      <head>
        <meta charSet="UTF-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <title>My App</title>
      </head>
      <body>
        <ProgressProvider>
          <Outlet />
        </ProgressProvider>
      </body>
    </html>
  )
}
```

## How It Works

The progress bar automatically appears during navigation:

- **Link clicks**: Progress starts when clicking `<Link>` components
- **Programmatic navigation**: Progress appears for `navigate()` calls
- **All routing events**: The provider listens to TanStack Router's `onBeforeLoad` and `onResolved` events

<Callout type="info" title="Simple & Automatic">
  No configuration needed! The progress bar works automatically for all navigation in your app.
</Callout>

## Manual Control

For advanced use cases, you can manually control the progress bar:

```tsx
import { useProgress } from '@bprogress/tanstack-router'

function MyComponent() {
  const { start, stop, pause, resume } = useProgress()

  return (
    <button onClick={() => {
      start()
      // ... perform some action
      stop()
    }}>
      Custom Action
    </button>
  )
}
```

See the [useProgress hook](/docs/react/hooks/use-progress) documentation for more details.
